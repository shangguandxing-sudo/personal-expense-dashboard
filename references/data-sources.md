# 数据来源与采集

## 支付流水

| 来源 | 取得方式 | 主要用途 |
| --- | --- | --- |
| 支付宝 | App 打开「我的 → 账单」，在更多菜单寻找「开具交易流水证明」或个人对账导出。网页可登录个人支付宝的「交易记录」，选择日期后按页面提供的格式下载。历史范围超过页面上限时分段保存，并核对首尾日期。 | 消费、退款、交易号、商户单号。历史网页导出可能缺扣款账户。 |
| 微信支付 | 微信「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单」。选个人对账版，按当前界面完成验证和收取文件。 | 消费、退款、交易单号、交易对方及支付方式。有时账单只给门店或商品简述。 |
| 储蓄卡、信用卡 | 在本人银行 App 或网银导出「交易明细」或「账单明细」。保留交易日、记账日、金额、币种、卡片别名、交易类型及能核实的交易引用号。只有 PDF 时，先按原表格整理到模板支持的列，并对照原文抽查金额与方向。 | 直营刷卡和支付平台覆盖不到的交易。区分借记卡、信用卡与平台扣款副本。信用卡还款单列为划转。 |

表格导出优先使用可机读格式。压缩包解压码由账单拥有者从官方通知取得并在本地使用。不同月份、银行卡及支付账号各保留一份原件与覆盖起止日。账单上有「截至」日期时采用该日期。最后一笔交易的日期只能证明记录到了那一笔。

入口依据：[支付宝消费记录帮助](https://cschannel.alipay.com/mobile/helpDetail.htm?help_id=201602030903) · [支付宝个人交易记录帮助目录](https://help.alipay.com/lab/cateQuestion.htm?cateId=237801&pageNo=3&pcateId=237328) · [财付通账单下载说明](https://pay.wechatpay.cn/xdc/weardeviceagreementweb/html/agreement/tenpay_user_privacy)

## 平台原订单

| 平台 | 读取位置与抓取字段 |
| --- | --- |
| 拼多多 | 在买家的「我的订单」打开详情，必要时展开。采订单编号、商品名称、规格、数量、店铺、下单或付款时间、整单实付、支付方式和可见售后信息。只采对账所需字段。 |
| 淘宝、淘宝闪购、京东等 | 从本人账号的已购订单或对应业务订单详情中取商品、规格、数量、优惠、运费、实付和退款。先判断是淘宝零售还是淘宝闪购。支付摘要里的「某店外卖订单」只够确认店铺。 |
| 美团外卖 | 从美团外卖的「订单」查看店铺、菜品、数量、优惠、配送费、实付和售后。官方说明订单页可查询近一年，超过一年可联系客服，实际以账号界面为准。 [美团外卖隐私政策](https://rules-center.meituan.com/m/detail/guize/137?activeRule=1&commonType=7) |
| 小红书等 | 在本人账号的购物订单详情或官方提供的订单明细文件中取商品。网页只看到社交页面、账单只有编号时，将对应项标为「商品名待补」。 |

优先用账号已提供的官方导出或本人已授权的可见订单页。没有买家批量入口时，按目标查可见订单，或者由用户决定是否向官方客服申请。排查咖啡、园艺等主题时可按商品和日期做定向补源，无需等全量订单拿齐。仅有截图时，记录页面可核实的字段和覆盖区间。将无法验证的历史订单或支付渠道列入待补清单。

字段依据：[拼多多订单信息说明](https://www.yangkeduo.com/pdd_privacy_policy.pdf) · [美团外卖订单字段说明](https://i.waimai.meituan.com/c/rules/%E7%BE%8E%E5%9B%A2%E5%A4%96%E5%8D%96%E7%94%A8%E6%88%B7%E6%9C%8D%E5%8A%A1%E6%9D%A1%E6%AC%BE%E6%9C%80%E6%96%B0%E7%89%88.html)
